## Решения
<!-- дата · этап · решение · почему · как поменять конфигом -->
- 06.10.2026 · M0 · Alembic живёт в `services/api` (`alembic.ini`, `migrations/`), `env.py` асинхронный (asyncpg), URL только из `DATABASE_URL`; ревизия `0001` делает лишь `CREATE EXTENSION IF NOT EXISTS timescaledb`, downgrade расширение не удаляет · схемой владеет API (FR-DB-01 sync справочников при старте api); `DROP EXTENSION` уничтожил бы гипертаблицы · `make migrate` (с хоста, `HOST_DATABASE_URL`), в контейнере `alembic -c services/api/alembic.ini upgrade head`.
- 06.10.2026 · M0 · Тесты — один корневой `tests/` по областям: `tests/twin_core`, `tests/services`, `tests/integration` (дальше `tests/sim`, `tests/e2e`, `tests/load` по SPEC §4.4); интеграционные помечены `@pytest.mark.integration` и не входят в `make check`, `make test` сам поднимает инфраструктуру; общие хелперы — `tests/support.py` · один прогон pytest на весь workspace; SPEC уже ссылается на `tests/sim/test_calibration.py` · маркеры и пути — `[tool.pytest.ini_options]` в `pyproject.toml`.
- 06.10.2026 · M0 · Формат Redis-ключа `plant:clock` — строка JSON v1: `{"v":1,"plant_time":"…Z","wall_ts":"…Z","speed":60.0,"paused":false,"sim_mode":"live"}`; читатели экстраполируют `plant_time + (wall_now − wall_ts) × speed` (на паузе — без экстраполяции); `sim` переписывает ключ при старте/паузе/смене скорости/сбросе и ~раз в секунду; `SimClock.is_stale` — нет обновлений > 10 с · `Clock.now()` синхронный и дешёвый, без запроса в Redis на каждый вызов; запись и чтение — `publish_clock_state` / `SimClock` в `twin_core.clock` · `CLOCK_MODE=sim|system`; формат описан в docstring `twin_core/clock.py`.
- 06.10.2026 · M0 · Значение `CLOCK_MODE` по умолчанию в коде — `system` (в `.env.example` и compose — `sim`) · библиотека и тесты на хосте не должны требовать Redis · переменная `CLOCK_MODE`.
- 06.10.2026 · M0 · Модели конфига строгие (`extra="forbid"`, неизвестный ключ — ошибка с подсказкой имени поля), дубли ключей YAML — ошибка; загрузчик собирает все проблемы сразу: файл, строка, путь с кодами (`areas[WELD].lines[WELD-1].ict_seconds`), значение, ближайший код (Левенштейн или единственное совпадение по подстроке); сервис с битым конфигом не стартует (код 2, список ошибок в stderr) · опечатка не должна молча превращаться в значение по умолчанию (AC M0, FR-DOM-01) · `python -m twin_core.config [DIR]` / `make config-check` для проверки.
