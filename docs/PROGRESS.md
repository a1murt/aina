- 07.10.2026 · M2 · Предвестники: `precursor(h)` в моделях сигналов растёт 0→1 только за h часов работы до ближайшего отказа по износовой причине; у случайных отказов предвестников нет ни в одном сигнале (SPEC §11.1). Выражение печи стало `140 + 8*precursor(2) + N(0, 1.2)`, у печи `wear_reasons: [EL-DRIVE]` (износа нет, d = 0; дрейф температуры предшествует только отказу привода) · честность модели PdM · `simulation.yaml: telemetry, failures.oven`.
- 07.10.2026 · M2 · Новые ключи `simulation.yaml` (валидируются `twin_core.config` с перекрёстными ссылками и тестами): `process.ckd_shortage_policy` (`resequence` по умолчанию | `wait`), `paint_filters.equipment_type`/`signal` (у каких единиц фильтры и какой сигнал их показывает; им же S2 задаёт ΔP), `defects.PAINT.humidity_signal` (полоса — `warn_lo..warn_hi` сигнала из `plant.yaml`), `defects.WELD.wear_equipment_type`, `degradation.*.pm_floor` (было только комментарием «минимум 0.05») · никаких кодов сигналов и типов в коде симулятора · правка YAML.

- 07.10.2026 · M2 · Перекраска: «перекраска или локальная доработка» решается по `rework.repaint_share` (0.4), тип дефекта — по весам внутри группы `repaint: true` / `false` (иначе доля перекраски была бы 0.30 от весов типов) · согласованно с быстрой моделью M6 · `plant.yaml: rework.repaint_share`, `simulation.yaml: defects.PAINT.types`.
- 07.10.2026 · M2 · Состояния: у оборудования — собственное состояние (`DOWN_*` > `IDLE_NO_PLAN` вне смены > `RUNNING`), голодание/блокировку линии оно не повторяет; линия — по приоритетам §5.3 (класс C не влияет, ёмкость = min `degraded_capacity`), причина `DOWN_*` линии — от раньше остановившейся единицы A.
