# Qost Twin

Цифровой двойник автомобильного завода, готовый к пилоту: виртуальный завод по OPC UA/MQTT, KPI по ISO 22400, живая схема цеха, терминал оператора, прогноз выполнения плана месяца с what-if, предиктивное ТО с объяснениями, сверка данных, LLM-рапорты. Кейс 2 Qostanai Industry Hackathon (организатор кейса — АО «Группа компаний АЛЛЮР»), Demo Day 16.10.2026.

## Что в этом пакете

## Как запустить работу в Claude Code
1. Создать пустой репозиторий, распаковать пакет в корень.
2. `git init && git add -A && git commit -m "spec"`
3. Запустить `claude` в корне репозитория и вставить промпт этапа M0 из `docs/SPEC.md` §18.2.
4. Дальше — по одному этапу за сессию; после каждого этапа `make check`, коммит и запись в `docs/PROGRESS.md`.
5. Параллельная работа команды — потоки A–D (SPEC §18), каждый в своей ветке.

## Требования к машине
Docker + Docker Compose, `make`, `uv` (Python 3.12), Node 20+ и `pnpm`; 8 ядер / 16 ГБ RAM для демо.

## После реализации
`make demo` — поднимает всё с нуля: миграции, пользователи всех ролей (пароль из `DEMO_PASSWORD`), история с 01.09.2026, импорт данных кейса, live-симуляция с 16.10.2026 07:00 на скорости 60×. Веб — http://localhost:3000, API — http://localhost:8000/api/docs.

Перегенерировать эталон (только при осознанном изменении формул/порогов): `python -I data/case/expected/compute_expected.py`.
