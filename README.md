# Aina


## Что в этом пакете
| Путь | Что |
|---|---|
| `docs/SPEC.md` | полное ТЗ: допущения, архитектура, домен и формулы, симулятор, сбор, БД, ядро, прогноз, ИИ, API, экраны, NFR, тесты, демо-сценарий, этапы M0–M9 с промптами |
| `config/` | модель завода (ISA-95), пороги и правила оповещений, причины простоев, коды дефектов, параметры виртуального завода, бизнес-допущения, контракт тегов OPC UA |
| `data/case/csv/` | те же данные в CSV и XLSX — для тестов импорта |
| `data/case/expected/` | эталонные значения (golden) и эталонный скрипт, который их считает |
| `tools/sim_sanity_check.py` | грубая проверка, что параметры симуляции дают целевые темп, брак и простои |
| `docs/PROGRESS.md` | журнал этапов и решений |
| `.env.example` | переменные окружения |

1. Создать пустой репозиторий, распаковать пакет в корень.
2. `git init && git add -A && git commit -m "spec"`
4. Дальше — по одному этапу за сессию; после каждого этапа `make check`, коммит и запись в `docs/PROGRESS.md`.
5. Параллельная работа команды — потоки A–D (SPEC §18), каждый в своей ветке.

## Требования к машине
Docker + Docker Compose, `make`, `uv` (Python 3.12), Node 20+ и `pnpm`; 8 ядер / 16 ГБ RAM для демо.

## После реализации

Перегенерировать эталон (только при осознанном изменении формул/порогов): `python -I data/case/expected/compute_expected.py`.
